# 0066 — Multiple Assignment & Destructuring

Swap two variables (`a = 1`, `b = 2`) with a single multiple-assignment, then unpack the pair `(3, 4)` into two variables — printing `2 1` then `3 4`. Swift swaps with the tuple assignment `(a, b) = (b, a)` and unpacks with `let (x, y) = (3, 4)`.

## Run

    swift main.swift
