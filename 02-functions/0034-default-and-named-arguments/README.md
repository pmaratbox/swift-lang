# 0034 — Default & Named Arguments

Give a `greet` function a default greeting, then call it once without the greeting and once overriding it, printing `Hello, Ada` and `Hi, Ada`. Swift parameters can have default values (`greeting: String = "Hello"`), and argument labels make most arguments named by default (`greeting: "Hi"`); the leading `_` here drops the label on `name`.

## Run

    swift main.swift
