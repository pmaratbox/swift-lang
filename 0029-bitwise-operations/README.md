# 0029 — Bitwise Operations

Compute bitwise AND, OR, and XOR on `6` and `3`, plus a left shift of `6` by one bit, printing `and: 2`, `or: 7`, `xor: 5`, and `shift: 12`. Swift's bitwise operators are `&`, `|`, `^`, and `<<` (with `~` for NOT). Arithmetic traps on overflow (`&+` wraps instead), while shifts use a smart, well-defined behavior; `6 << 1` doubles to 12.

## Run

    swift main.swift
