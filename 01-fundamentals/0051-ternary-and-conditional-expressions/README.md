# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Swift's `?:` ternary conditional operator chooses between two expressions inline. The `if`/`switch` *expression* forms (Swift 5.9+) are the multi-line alternative.

## Run

    swift main.swift
