# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. `String(n, radix:)` renders an integer in any base from 2 to 36, so radix 16, 8, and 2 give hex, octal, and binary. Pass `uppercase: true` for uppercase hex digits.

## Run

    swift main.swift
