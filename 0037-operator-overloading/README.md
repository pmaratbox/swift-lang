# 0037 — Operator Overloading

Define how `+` (or an `add` method) combines two points, then add `(1, 2)` and `(3, 4)` and print `(4, 6)`. Operators are static functions: `static func + (a: Point, b: Point)` overloads `+`. Swift even lets you define brand-new operators and set their precedence and associativity.

## Run

    swift main.swift
