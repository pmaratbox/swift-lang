# 0024 — Sorting & Comparators

Sort `[3, 1, 2]` ascending, then again with a custom comparator that reverses the order, printing `asc: 1 2 3` and `desc: 3 2 1`. `sorted()` returns a new array in ascending order; `sorted(by:)` takes a predicate, and passing the `>` operator sorts descending. The in-place form is `sort()`, which reorders the array directly.

## Run

    swift main.swift
