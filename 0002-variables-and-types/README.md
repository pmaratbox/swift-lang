# 0002 — Variables & basic types

Declare bindings of Swift's four basic types (`Int`, `Double`, `String`,
`Bool`) and print each via string interpolation with `\(...)`. The type
annotations are optional — Swift would infer the same types from the
literals — and `let` makes each binding immutable. Swift prints booleans
as lowercase `true`/`false`.

## Run

    swift main.swift
