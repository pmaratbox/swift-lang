# 0056 — Linked List

Build a singly-linked list holding `1`, `2`, and `3`, then traverse it from head to tail and print `1 -> 2 -> 3`. `Node` must be a `class` (a reference type) so it can hold a `Node?` to the next node — a `struct` cannot contain itself without indirection. `while let` unwraps the optional cursor.

## Run

    swift main.swift
