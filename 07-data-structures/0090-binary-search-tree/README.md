# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. `Node` is a `class` (reference type) so subtrees can be optional references; `insert` recurses by comparison and in-order traversal collects sorted values.

## Run

    swift main.swift
