# 0081 — Set Operations

Compute the union and intersection of the sets `{1, 2, 3}` and `{2, 3, 4}`, printing the union `1 2 3 4` and the common elements `2 3` (each in ascending order). `Set.union`/`intersection` return new sets; `sorted()` orders them since a `Set` has no defined order.

## Run

    swift main.swift
